科研项目信息化管理平台 · 目标机部署包（2026-08-21）

【这是什么】
把本平台装到另一台已在运行「表单维护工具」（8092）的 Linux 服务器上。
安装后把那台机器上 8092 的台账行接入本平台。登录页只显示工号+密码，不展示人员快捷入口。

【最短步骤】（目标机已装 Docker，8092 已在跑）
1. 把本文件夹上传到目标机，例如 /opt/srpm
2. cd /opt/srpm
   chmod +x *.sh
   sudo bash ./install.sh
3. sudo bash ./attach-form-ledger.sh
4. sudo bash ./verify.sh
5. 浏览器打开 http://目标机IP:18087/
   管理员：工号 100001    密码 100001
   Ctrl+F5 后看「项目台账 / 表单维护」，行数应与本机 8092 一致。

【可登录账户】（登录页不列出这些人，需自己输入工号）
工号即初始密码。详见《部署步骤.txt》。

【禁止】
- 不要 docker compose down -v
- 不要 docker volume rm platform_srpm-data（有数据时）
- 不要把 8092 的 platform.db 整文件拷进本平台
- 不要停、不要改 8092 容器和数据卷

【本包不含】
- 36 服务器上的业务 sqlite（目标机应接入本机 8092）
- AI 密钥
